# Hydrant Halo — Frontend

Next.js 14 (App Router) + TypeScript + Tailwind + Leaflet/OpenStreetMap. Dark command-center UI.

```bash
cp .env.local.example .env.local
npm install
npm run dev   # http://localhost:3000
```

Routes: `/` map + incident sidebar · `/incidents` · `/tasks` community task board · `/verify` Gemini photo verification · `/rewards` Solana payouts · `/analytics` Tiger Data charts & risk ranking.
